# Process

I processed the Hong Kong Observatory CSV data and create the final visualisation.

## Tools

I used ChatGPT during the design and coding process. I used it mainly to discuss possible visual directions, modify the plotting code, and improve the visual presentation of the data.

## Kept

The  AI suggestion I kept was the idea of representing cloud amount as the height of a continuous cloud layer.

I also kept the suggestion to use a moving average for the visual boundary. The original daily data contains many sharp day-to-day changes, so the raw line produced a very hard and mechanical shape. A 7-day moving average made the boundary visually softer while still showing the overall changes in cloud cover.

## Rejected

I rejected the  vertical-layer/bar-chart version suggested during the design process. Although each bar correctly represented one day's cloud amount, the dense vertical bars made the image look more like an audio waveform or volume-level visualisation.

I also rejected versions with a strong outline around . The outline made the data easier to distinguish, but it made the visualisation feel more like a conventional chart .
